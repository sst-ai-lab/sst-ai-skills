# Security Skill

- Check authentication and authorization boundaries.
- Check input validation and injection risks.
- Check sensitive data and secret handling.
- Check insecure deserialization and unsafe external input usage.
- Check access control and privilege escalation risks.
- Check cryptographic and transport security assumptions.
- Check dependency or configuration changes that weaken security.
- Report only actionable security findings related to the reviewed change.
