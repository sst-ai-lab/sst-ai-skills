# cm-be-bff-web

Các skill riêng của `cm-be-bff-web`. Bật cùng với `sst-common`, `sst-be-common` và `cm-be-bff-common`.

```json
{ "enabledPlugins": { "sst-common@sst-ai-skills": true, "sst-be-common@sst-ai-skills": true, "cm-be-bff-common@sst-ai-skills": true, "cm-be-bff-web@sst-ai-skills": true } }
```

| Skill | Mục đích |
| --- | --- |
| `scaffold-report` | Feature báo cáo JasperReports (phần nối ở BFF, row map, quy tắc `.jrxml`) |
| `scaffold-integration` | Feature tích hợp bên ngoài, bọc SDK của nhà cung cấp (Azure / Bedrock) |
