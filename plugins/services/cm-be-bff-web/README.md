# cm-be-bff-web

Skills specific to `cm-be-bff-web`. Enable together with `sst-common`, `sst-be-common` and `cm-be-bff-common`.

```json
{ "enabledPlugins": { "sst-common@sst-ai-skills": true, "sst-be-common@sst-ai-skills": true, "cm-be-bff-common@sst-ai-skills": true, "cm-be-bff-web@sst-ai-skills": true } }
```

| Skill | Purpose |
| --- | --- |
| `scaffold-report` | JasperReports report feature (BFF glue, row map, `.jrxml` rules) |
| `scaffold-integration` | External integration feature wrapping a vendor SDK (Azure / Bedrock) |
