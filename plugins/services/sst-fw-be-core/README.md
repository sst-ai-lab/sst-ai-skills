# sst-fw-be-core

Skills specific to `sst-fw-be-core`. Enable together with `sst-common`, `sst-be-common` and `sst-fw-be-common`.

```json
{ "enabledPlugins": { "sst-common@sst-ai-skills": true, "sst-be-common@sst-ai-skills": true, "sst-fw-be-common@sst-ai-skills": true, "sst-fw-be-core@sst-ai-skills": true } }
```

| Skill | Purpose |
| --- | --- |
| `scaffold-constraint` | Custom Bean Validation constraint (annotation, validator, example DTO, message keys) |
| `write-extensions` | Rules for extension utility classes |
