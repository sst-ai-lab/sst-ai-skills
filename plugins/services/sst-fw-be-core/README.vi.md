# sst-fw-be-core

Các skill riêng của `sst-fw-be-core`. Bật cùng với `sst-common`, `sst-be-common` và `sst-fw-be-common`.

```json
{ "enabledPlugins": { "sst-common@sst-ai-skills": true, "sst-be-common@sst-ai-skills": true, "sst-fw-be-common@sst-ai-skills": true, "sst-fw-be-core@sst-ai-skills": true } }
```

| Skill | Mục đích |
| --- | --- |
| `scaffold-constraint` | Constraint Bean Validation tùy chỉnh (annotation, validator, DTO ví dụ, message key) |
| `write-extensions` | Quy tắc cho các class extension utility |
