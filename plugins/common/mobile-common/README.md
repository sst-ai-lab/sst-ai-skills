# mobile-common

Shared commands for SCM Flutter repositories (`cm-fe-mobile`, `sst-fw-mobile`, `sst-fw-widgetbook`).

```json
{ "enabledPlugins": { "mobile-common@sst-ai-skills": true } }
```

## Contents

| Command | Purpose | Migrated from (Copilot) |
|---|---|---|
| `/mobile-common:create-comment <file>` | Add Japanese Dart comments to a file without changing code | `.github/prompts/create-comment.prompt.md` (identical in all 3 repos) |
