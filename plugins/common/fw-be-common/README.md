# fw-be-common

Shared skills for SST backend framework repositories (`sst-fw-be-*`).

## Contents

No skills yet. The Copilot sources in the `sst-fw-be-*` repositories are only repository-level `copilot-instructions.md` files (build, CI, commit and house-style facts), which belong in each repository's `CLAUDE.md`, not in a skill.
