# Copilot → Claude Code migration notes

Migration of the GitHub Copilot customizations in `origin-source/*/.github` into this marketplace. Content was **moved, not rewritten**: only format and mechanics were adapted (skill layout, `read_file` → Read, `applyTo` instructions → skill references, prompts → commands, service names → placeholders in common plugins). Stale or contradictory content was intentionally kept and is listed here for follow-up.

## Not migrated

| Source | Reason |
|---|---|
| `*/.github/copilot-instructions.md` (all repositories) | Repository facts → each repository's `CLAUDE.md` |
| `cm-be-bff-{api,web}/.agents/skills/{code-reviewer,java-springboot}` | Vendored third-party skills that contradict SST conventions (JPA, package-by-feature, `npm run preflight`) |
| `cm-be-ms-manual/.github/**` | Copy of `cm-be-ms-bill` with "bill" renamed to "manual"; describes the wrong service |
| `cm-be-bff-api/.github/skills/backend/references/init.md` | Older copy of `cm-be-bff-web`'s |
| `manual-fe-web/.github/**` | Older copy of `cm-fe-web`'s; conflicting items listed below |
| `cm-be-ms-{bill,core,inout,owner}` `skills/backend/SKILL.md` | Merged into `backend-common:ms-scaffold` |

## Must be provided by repository CLAUDE.md

Migrated skills now point to the repository `CLAUDE.md` for:

- `## Service profile` / `## Policies` values used by common skills (see each plugin README).
- `frontend-common`: `{middleCategoryDirs}` / `{subCategoryDirs}` directory tables, `{menuFile}`, `{commonLookupImportPath}`, `{dropDownApiDir}`.
- `sst-fw-be-core`: the "Custom Validation Annotations" and "Extension Utilities" sections currently in its `copilot-instructions.md`.
- `cm-be-bff-web`: the `要確認` marker convention.
- `cm-be-ms-log` / `cm-be-ms-dailyinv`: naming table, `@Mapper` header, dual-datasource MyBatis table.

## Decisions needed (content kept as-is until decided)
